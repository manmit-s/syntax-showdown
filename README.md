# 1v1 Code Clash Arena

A real-time 1v1 competitive programming platform built with Streamlit, Google Gemini, and Firebase Firestore.

## Setup

1. Install dependencies:
   ```bash
   pip install -r requirements.txt
   ```

2. Configure secrets:
   - Copy `.streamlit/secrets.toml.example` to `.streamlit/secrets.toml`
   - Add your API keys and Firebase credentials

3. Run locally:
   ```bash
   streamlit run app.py
   ```

## Deployment

Deploy to Streamlit Community Cloud. Add secrets via App Settings → Secrets.
